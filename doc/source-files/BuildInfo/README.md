# BuildInfo Module Documentation

## Overview

The BuildInfo module provides version and build timestamp information for the artdaq-database package. It implements the standard artdaq pattern for embedding and accessing build metadata at runtime.

## Module Location

**Path**: `/home/user/artdaq-database/artdaq-database/BuildInfo/`

## Purpose

Enable runtime access to:
- Package version number with git information
- Build timestamp
- Package name

This information is used for:
- Version checking and compatibility verification
- Diagnostic logging and error reporting
- Build tracking and debugging
- User information display

## Architecture

### Design Pattern

**Static Utility Class**:
```cpp
namespace artdaqdatabase {
  struct GetPackageBuildInfo {
    static artdaq::PackageBuildInfo getPackageBuildInfo();
  };
}
```

**Benefits**:
- No instantiation required
- Simple API
- Standard across artdaq packages
- Thread-safe (stateless)

### Build-Time Code Generation

```
GetPackageBuildInfo.cc.in  →  CMake Processing  →  GetPackageBuildInfo.cc
    (with @placeholders@)         (substitution)        (with actual values)
```

**Substituted Variables**:
- `@version_with_git@` → Git version string
- `@utcDateTime@` → Build timestamp

## Key Components

### GetPackageBuildInfo Class

**Namespace**: `artdaqdatabase`

**Single Method**:
```cpp
static artdaq::PackageBuildInfo getPackageBuildInfo()
```

**Returns**: Populated `artdaq::PackageBuildInfo` object with:
- Package name: "artdaq-database"
- Version: From git describe
- Timestamp: From build time

### Version Information

**Format**: `vMAJOR_MINOR_PATCH[-commits]-g[hash]`

**Examples**:
- Release: `v1_05_00`
- Development: `v1_05_00-1-g5e0d18a`

**Source**: `git describe --tags --always --dirty`

### Timestamp Information

**Format**: ISO 8601 with UTC timezone

**Example**: `2025-11-13 15:30:45 UTC`

**Source**: CMake build time

## Usage Examples

### Basic Usage

```cpp
#include "artdaq-database/BuildInfo/GetPackageBuildInfo.hh"

// Get build info
auto info = artdaqdatabase::GetPackageBuildInfo::getPackageBuildInfo();

// Display version
std::cout << "Version: " << info.getPackageVersion() << "\n";
```

### Version Checking

```cpp
void checkMinimumVersion(std::string const& required) {
  auto info = artdaqdatabase::GetPackageBuildInfo::getPackageBuildInfo();
  auto version = info.getPackageVersion();

  if (compareVersions(version, required) < 0) {
    throw std::runtime_error(
      "Requires artdaq-database >= " + required +
      ", but found " + version
    );
  }
}
```

### Diagnostic Logging

```cpp
void logStartup() {
  auto info = artdaqdatabase::GetPackageBuildInfo::getPackageBuildInfo();

  LOG(INFO) << "Starting " << info.getPackageName();
  LOG(INFO) << "Version: " << info.getPackageVersion();
  LOG(INFO) << "Built: " << info.getBuildTimestamp();
}
```

### Command-Line Version Display

```cpp
int main(int argc, char* argv[]) {
  if (argc > 1 && std::string(argv[1]) == "--version") {
    auto info = artdaqdatabase::GetPackageBuildInfo::getPackageBuildInfo();
    std::cout << info.getPackageName() << " "
              << info.getPackageVersion() << "\n";
    return 0;
  }
  // ... normal operation
}
```

## CMake Build Process

### Version Extraction

```cmake
# Get version from git
execute_process(
  COMMAND git describe --tags --always --dirty
  OUTPUT_VARIABLE version_with_git
  OUTPUT_STRIP_TRAILING_WHITESPACE
)
```

### Timestamp Generation

```cmake
# Get current UTC time
string(TIMESTAMP utcDateTime "%Y-%m-%d %H:%M:%S UTC" UTC)
```

### Template Configuration

```cmake
# Process template

  ${CMAKE_CURRENT_SOURCE_DIR}/GetPackageBuildInfo.cc.in
  ${CMAKE_CURRENT_BINARY_DIR}/GetPackageBuildInfo.cc
  @ONLY
```

## Advantages

### Compile-Time Embedding

**Benefits**:
- No external files needed at runtime
- No file I/O overhead
- Always available
- Cannot be corrupted or lost

### Git Integration

**Benefits**:
- Exact commit identification
- Development vs release distinction
- Dirty workspace detection
- Automatic versioning

### UTC Timestamps

**Benefits**:
- Unambiguous across timezones
- Sortable
- ISO 8601 standard
- Build reproducibility tracking

## Limitations

### Build Timestamp Non-Reproducibility

**Issue**: Timestamps change even with identical source

**Impact**:
- Breaks bit-for-bit reproducible builds
- Cache invalidation in build systems

**Mitigation**:
- Can be disabled if needed
- Not critical for functionality

### Git Dependency

**Issue**: Requires git repository

**Impact**:
- Build from tarball needs version injection
- Cannot determine version without git

**Mitigation**:
- Release tarballs pre-configure version
- Fallback to hardcoded version possible

### Static Information

**Issue**: Fixed at compile time

**Impact**:
- Cannot update without recompilation
- Binary contains outdated info after updates

**Design Choice**:
- Intentional - reflects binary provenance
